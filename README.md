# Data and code for urban boundary-layer vertical decoupling analysis

This release contains sanitized derived data tables, portable plotting scripts
and prebuilt figure assets for an urban boundary-layer vertical decoupling
analysis. It is intentionally journal-neutral and does not expose submission-
package naming or private local paths.

## Contents

- `data/`: figure-ready source tables, city-domain manifests and indicator definitions.
- `figures/`: prebuilt PNG, PDF, SVG and TIFF assets for the five main figures.
- `scripts/`: portable figure-building and integrity-check utilities.
- `tables/`: exported source-data tables for the mechanism diagnostic and Paris lidar figure.
- `reports/`: lightweight release QA notes generated by the portable scripts.

The release does not redistribute complete upstream ERA5 archives, complete raw
Paris Doppler wind lidar files, credentials, local working directories or
intermediate caches. Upstream public datasets retain their original licenses.

## Quick check

```bash
python scripts/check_release_integrity.py
```

## Rebuild figures

```bash
python scripts/build_figure_1.py
python scripts/build_figure_3.py
python scripts/build_figure_4.py
python scripts/build_figure_2_and_5.py
```
